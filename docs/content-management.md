# iLENS website content management

The public site is intentionally kept simpler than the underlying research information system.

## Edit these first

Most day-to-day updates should happen in `ilens-data`:

- `people/` — members and alumni
- `projects/` — research projects
- `publications/` — publications after Zotero/metadata curation
- `datasets/` — public datasets
- `software/` — public software
- `institutions/` — collaborators and funders
- `grants/` — funding information

The website consumes generated data from `ilens-data` rather than duplicating the same information in page templates.

## Edit the website directly only for

- About text
- Join Us text
- research-area descriptions
- navigation
- visual/layout changes

## Public-site principle

The public site emphasizes:

1. Research
2. Projects
3. People
4. Publications
5. Data & Software
6. About
7. Opportunities / Join Us

Internal research-system entities such as research questions, methods, experiments, claims, evidence, knowledge graphs, and planned observatories remain available to the infrastructure but are not primary navigation items.

## Before publishing

Do not publish placeholder records, example DOIs, invented links, or planned observatories as if they were operational. A record should appear publicly only when its metadata is curated and accurate.
